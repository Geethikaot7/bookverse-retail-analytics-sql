# 📚 BookVerse Retail Analytics – SQL Project

## 📌 Project Overview

BookVerse is an online bookstore. This project uses SQL to analyze retail data and generate business insights related to sales, customers, books, authors, genres, and revenue.

The objective of this project is to transform raw transactional data into meaningful business insights that can support business decision-making.

## 🎯 Business Objectives

- Understand overall sales performance
- Identify top-performing books
- Analyze revenue by genre
- Identify high-performing authors
- Understand customer purchasing behavior
- Identify high-value customers
- Analyze monthly revenue trends
- Identify opportunities to improve sales performance

## 🛠️ Tools & Technologies

- MySQL
- SQL
- CTEs
- Window Functions
- Aggregate Functions
- Joins
- Subqueries

## 📂 Dataset

The project contains data related to:

- Books
- Customers
- Orders

The data was analyzed using SQL queries to understand sales performance and customer purchasing behavior.

## 🔍 Analysis Performed

### 📊 Sales Analysis

- Total number of orders
- Total quantity sold
- Total revenue
- Top-performing books
- Monthly revenue trends

### 📚 Book Analysis

- Top 5 books by revenue
- Top 5 books by quantity sold
- Book-level sales performance

### 🏷️ Genre Analysis

- Revenue generated by each genre
- Average book price by genre
- Number of books in each genre

### ✍️ Author Analysis

- Revenue generated by authors
- Identification of high-performing authors

### 👥 Customer Analysis

- Customer revenue contribution
- Identification of high-value customers
- Customer purchasing behavior

### 📈 Advanced SQL Analysis

- Common Table Expressions (CTEs)
- RANK()
- DENSE_RANK()
- PARTITION BY
- Aggregate Functions
- JOINs
- Subqueries

## 💡 Key Business Insights

The analysis identified important patterns in sales, customer purchasing behavior, book performance, genre performance, author performance, and revenue trends.

## 💼 Business Recommendations

- Maintain sufficient inventory for high-demand books.
- Promote high-revenue and high-demand books.
- Focus marketing efforts on high-performing genres.
- Develop targeted offers for high-value customers.
- Monitor monthly revenue trends regularly.
- Analyze low-performing books and identify opportunities for improvement.
- Use sales and customer insights to support data-driven business decisions.
